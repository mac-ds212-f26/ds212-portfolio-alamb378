Code
pal <- colorFactor(palette = "YlOrRd", domain = grambank_languages$macroarea)


leaflet(data = grambank_languages) |> 
  addProviderTiles("Esri.WorldStreetMap") %>%
  addCircles(label = grambank_languages$family_name, 
             color = ~pal(grambank_languages$macroarea)) |> 
  addLegend("bottomright", pal = pal, values = ~grambank_languages$macroarea, title = "Macro Area") |> 
  addControl("<h4>Are languages more consitiant with there macro area</h4>", position = "topleft") |> 
  addControl("<h10>Lanuages stay in there macro area</h10>", position = "topleft") |> 
  addControl("<p>By: Andrew Lamb, Created:11/9/26, Data:Grambank, TidyTuesday 11/3/26</p>", position = "bottomleft")

The language families do spatial stay in the same region as others in the same family.

Now that we have the popularity, where are the languages that stem from the ten most popular language origns?

Code
pop_lang <- grambank_languages |> 
  mutate(lang_og = sub("(/.*)", "", lineage)) |> 
  filter(!is.na(lang_og)) |> 
  group_by(lang_og) |> 
  summarise(popularity = n()) |> 
  arrange(desc(popularity)) |> 
  head(10)

langs_w_most_common_roots <- grambank_languages |> 
  mutate(lang_og = sub("(/.*)", "", lineage)) |> 
  filter(!is.na(lang_og)) |> 
  semi_join(pop_lang)

Conclusion

Languages that come from the ten most popular langauge origns sit on what looks to be a line that runs through Subsahairn Africa, South East Asia, into Australia. There deosn’t seem to be a lot of languags that stem from these top ten in the Americas , Northern Asia and Russia.
